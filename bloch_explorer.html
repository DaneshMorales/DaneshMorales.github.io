Target density matrix ρ★
ρ(v) = ½ [[1 + z, x − iy], [x + iy, 1 − z]]

Into the target frame, apply the mixture, then rotate back. U maps the +z axis to the target direction n, so U† is the into-frame rotation.

Φ(ρ) = U { r Aλ(U†ρU) + (1 − r) Dp(U†ρU) } U†
Dp(ρ) = (1 − p)ρ + pI/2
K₀ = diag(1, √(1 − λ)),   K₁ = [[0, √λ], [0, 0]]
Aλ(ρ) = K₀ρK₀† + K₁ρK₁†

The browser evaluates the exact, equivalent Bloch dynamics. With n = v★/t, a = r√(1 − λ) + (1 − r)(1 − p), and b = r(1 − λ) + (1 − r)(1 − p):

vₖ₊₁ = a vₖ + [(b − a)(vₖ · n) + rλ] n
vₖ − v★ = aᵏ(v₀ − v★)⊥ + bᵏ(v₀ − v★)∥

For the fixed positive λ and p above, r = tp / [λ(1 − t) + tp] makes ρ★ the unique fixed state. A pure target gives r = 1; a maximally mixed target gives r = 0. At the centre the axis is arbitrary and the channel is simply depolarizing. When both selected states are equal, the trajectory is stationary.

The distance is evaluated directly from the decaying perpendicular and parallel components to avoid cancellation near the target. A finite k is not infinity: the k → ∞ button displays the analytic limit explicitly. This is evolution of the unconditional density matrix under a convex mixture, not a randomly sampled channel history.
