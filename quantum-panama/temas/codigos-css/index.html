De códigos clásicos a códigos cuánticos: construcción CSS

Pregunta de investigación¿Cómo se transforma un código corrector clásico en uno que protege información cuántica?

  • Matemática pura
  • Programación
  • Teoría
  • Simulación y cómputo
Me interesa este tema

En pocas palabras

Muchos códigos cuánticos se construyen a partir de dos códigos clásicos. Este tema recorre esa construcción, llamada CSS (Calderbank–Shor–Steane), con el código de Steane como ejemplo central.

Materias y conocimientos útiles

Para empezar

  • Álgebra lineal
  • Algo de álgebra abstracta

Se aprende durante el proyecto

  • Códigos lineales binarios y matrices de chequeo
  • Formalismo de estabilizadores
  • Construcción CSS y código de Steane

Pensado para: Estudiantes de Matemática con álgebra lineal y algo de álgebra abstracta.

Buena entrada. El documento lo señala como buena entrada para estudiantes de Matemática. El curso de IBM sobre corrección de errores es un punto de partida.

Qué harías

Desarrollarías la teoría de códigos binarios, matrices de chequeo, estabilizadores y la construcción CSS, usando el código de Steane como ejemplo central. Implementarías un programa que verifique la conmutación de los estabilizadores, el número de qubits lógicos y la distancia en ejemplos pequeños. Como extensión, estudiarías un conjunto acotado de modificaciones de las matrices de chequeo.

Cómo se limita el alcance

  • Ejemplos pequeños, verificables por computadora.
  • La extensión se limita a un conjunto acotado de modificaciones de las matrices de chequeo.

Producto esperado

Una exposición matemática rigurosa acompañada de una herramienta reproducible para analizar códigos.

  • Exposición rigurosa
  • Código reproducible

Artículos y recursos iniciales

  1. A. R. Calderbank y P. W. Shor (1996). Good quantum error-correcting codes exist. Physical Review A 54, 1098. DOI · arXiv:quant-ph/9512032
  2. IBM Quantum Learning. Foundations of quantum error correction. Curso en línea. Estabilizadores, códigos CSS y código tórico. En inglés. Abrir recurso
