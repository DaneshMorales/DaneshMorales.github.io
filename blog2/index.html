Key things to memorize
  • CPTP map: $\varepsilon(\rho) = \sum_i K_i \rho K_i^\dagger$, with completeness $\sum_i K_i^\dagger K_i = I$
  • Kraus operators are not unique — any unitary rotation of the Kraus set gives the same channel
  • This notation is the universal language of every paper in this project
Why this matters
  • Every noise model in Tasks 1–5 is a sequence of CP maps organized into a process tensor
  • The error operator $\mathbf{E}$ in eq.(2) of the strategic code paper IS a sequence of CP maps
